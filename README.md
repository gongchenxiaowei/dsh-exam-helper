# dsh-exam-helper

DSH 插件：把「读屏做题」里**机械的那一半**固化下来，答案仍由模型判断。

## 为什么要有它

靠模型目测截图坐标去点选项，页面一滚动就点歪；选项顺序还会随机重排，记字母没用。
这个插件把坐标、翻页、交卷这些动作交给代码，答案留给模型——两边各干擅长的。

## 工具

| 工具 | 作用 |
| --- | --- |
| `exam_state` | 读当前题：题型、题干、选项（字母 + 内容 + 真实纵坐标）、导航、进度 |
| `exam_pick` | 选选项：`letters:"AC"` 或 `match:"文字片段"`；选完自动回读 |
| `exam_next` / `exam_prev` | 翻页，没有可读节点时走截图像素兜底 |
| `exam_screen` | 截图（图片题/公式题给模型看），可裁 top / options / full |
| `exam_submit` | 交卷，**必须 `confirm:true`**；先点提交再点弹窗确认 |
| `exam_open` | 把学习通 / 知到切到前台（防止点到别的窗口） |

## 原理

1. **文字节点优先**：DSHA 的 `/app/ui/dump` 给了每个节点的真实中心点，直接点，不做坐标算术。
2. **像素兜底**：H5 页面（超星数学题那种）读不到节点时，`lib/finder.py` 用 PIL 找蓝色选项框和底部按钮。
3. **内容匹配**：选项顺序每次刷新都会变，所以 `exam_pick` 既支持字母也支持按内容片段选。

## 依赖

- 手机上有 DSHA（桥在 `127.0.0.1:3090`，token 在 `~/.dsh/.bridge_token`）
- 系统里能跑 `python3` + `PIL`（像素兜底才需要；纯文字页面不依赖）

## 边界

- 不内置答案库，不评判对错
- 不会自动提交：`exam_submit` 没有 `confirm:true` 就拒绝
- 考试诚信由使用者自己把握
